# V1 实施计划

## 一、实施顺序

| 步骤 | 内容 | 说明 |
|------|------|------|
| 1 | 数据库 Schema 修改 | 新增 customers、opportunities，扩展 orders |
| 2 | 执行 db push | 应用 schema 变更 |
| 3 | 导航菜单调整 | Header 改为 5 个菜单项 |
| 4 | 客户模块 | 列表、新建、详情 |
| 5 | 商机模块 | 列表、新建、详情、转订单 |
| 6 | 订单模块升级 | 列表主状态+标签、详情 Tab |
| 7 | 用户管理（管理员） | 列表、新建 |

## 二、Prisma Schema 变更

### 新增枚举
- MainStatus: OPPORTUNITY, CONVERTED, IN_PRODUCTION, PENDING_SHIPMENT, COMPLETED, CANCELLED
- IntentionLevel: HIGH, MEDIUM, LOW
- ProductionMode: SELF, OUTSOURCE, MIXED
- PaymentStatus: UNPAID, PARTIAL, PAID

### 新增表
- Customer
- Opportunity

### Order 扩展字段（均可选，保证平滑升级）
- customerId, opportunityId
- mainStatus, isQuoted, intentionLevel, productionMode
- hasSelectedSupplier, customerPaymentStatus, supplierPaymentStatus

## 三、页面变更清单

### 新增
- /customers - 客户列表
- /customers/new - 新建客户
- /customers/[id] - 客户详情
- /opportunities - 商机列表
- /opportunities/new - 新建商机
- /opportunities/[id] - 商机详情
- /admin/users - 用户管理（仅管理员）

### 修改
- Header - 导航菜单
- /orders - 列表增加主状态、辅助标签
- /orders/[id] - 详情增加 Tab（基本信息、产品明细、外放信息、收付款）
- /orders/new - 支持从商机转、选择客户

### 保留
- /quote/[token] - 外协填写页
- /login - 登录

## 四、API 变更

### 新增
- /api/customers (GET, POST)
- /api/customers/[id] (GET, PUT)
- /api/opportunities (GET, POST)
- /api/opportunities/[id] (GET, PUT)
- /api/opportunities/[id]/convert - 转订单
- /api/admin/users (GET, POST) - 仅管理员

### 修改
- /api/orders - 支持 mainStatus 等筛选，返回新字段
