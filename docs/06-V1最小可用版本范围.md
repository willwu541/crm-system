# 外采加工询价管理系统 - V1 最小可用版本范围

## 一、V1 必须实现

### 1. 认证
- [x] 内部用户登录（邮箱 + 密码）
- [x] 登出
- [x] 基于 Session 的权限控制
- [x] 角色：管理员、业务员（业务员只能看自己的订单）

### 2. 订单管理
- [x] 新建订单（主信息 + 多明细）
- [x] 订单列表（分页、状态筛选）
- [x] 订单详情查看与编辑
- [x] 动态增删订单明细
- [x] 订单级附件上传
- [x] 明细级附件上传

### 3. 外协链接
- [x] 生成唯一 token 链接
- [x] 链接过期时间设置
- [x] 外协填写页（无需登录）
- [x] 外协提交报价

### 4. 报价回收
- [x] 查看订单下所有报价
- [x] 表格对比每家工厂每个明细价格
- [x] 按总价、交期、提交时间排序
- [x] 标记意向/中选厂家

## 二、V1 不实现（预留扩展）

- Excel 导出
- PDF 导出
- 消息/邮件提醒
- 管理员用户管理界面（可先手动在数据库添加用户）
- 复杂权限配置
- 订单删除（可先只做状态关闭）

## 三、V1 验收标准

1. 业务员可登录并创建带多明细的订单
2. 可上传订单级和明细级附件
3. 可生成外协链接并复制
4. 外协户打开链接可填写报价并提交
5. 后台可查看所有报价并比价、标记中选
