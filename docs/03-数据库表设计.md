# 外采加工询价管理系统 - 数据库表设计

## 一、ER 关系概览

```
User (用户)
  └── Order (订单) 1:N
        ├── OrderItem (订单明细) 1:N
        ├── OrderAttachment (订单附件) 1:N
        ├── QuoteLink (外协链接) 1:N
        └── Quote (报价) 1:N
              └── QuoteItem (报价明细) 1:N
```

## 二、表结构详情

### 2.1 User（用户表）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | String (UUID) | 主键 |
| email | String | 登录邮箱，唯一 |
| passwordHash | String | 密码哈希 |
| name | String | 姓名 |
| role | Enum (ADMIN, SALES) | 角色 |
| createdAt | DateTime | 创建时间 |
| updatedAt | DateTime | 更新时间 |

### 2.2 Order（订单表）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | String (UUID) | 主键 |
| orderNo | String | 订单编号，唯一 |
| customerName | String | 客户名称 |
| contactName | String | 联系人 |
| contactPhone | String | 联系电话 |
| projectName | String | 项目名称 |
| deliveryRegion | String | 交货地区 |
| quoteDeadline | DateTime? | 报价截止时间 |
| remark | String? | 总体备注 |
| status | Enum (DRAFT, PUBLISHED, CLOSED) | 订单状态 |
| createdById | String | 创建人（业务员） |
| createdAt | DateTime | 创建时间 |
| updatedAt | DateTime | 更新时间 |

### 2.3 OrderItem（订单明细表）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | String (UUID) | 主键 |
| orderId | String | 订单 ID |
| sortOrder | Int | 排序序号 |
| productType | String | 产品类型 |
| specModel | String | 规格型号 |
| dimensions | String? | 尺寸 |
| quantity | Decimal | 数量 |
| unit | String | 单位 |
| surfaceTreatment | String? | 表面处理 |
| specialRequirement | String? | 特殊要求 |
| remark | String? | 明细备注 |
| createdAt | DateTime | 创建时间 |
| updatedAt | DateTime | 更新时间 |

### 2.4 OrderAttachment（订单附件表）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | String (UUID) | 主键 |
| orderId | String | 订单 ID |
| orderItemId | String? | 订单明细 ID（为空表示订单级附件） |
| fileName | String | 文件名 |
| filePath | String | 存储路径 |
| fileSize | Int | 文件大小（字节） |
| mimeType | String | MIME 类型 |
| createdAt | DateTime | 创建时间 |

### 2.5 QuoteLink（外协链接表）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | String (UUID) | 主键 |
| orderId | String | 订单 ID |
| token | String | 唯一 token |
| supplierName | String? | 供应商名称（可选备注） |
| expiresAt | DateTime? | 过期时间 |
| createdAt | DateTime | 创建时间 |

### 2.6 Quote（报价表）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | String (UUID) | 主键 |
| orderId | String | 订单 ID |
| quoteLinkId | String | 外协链接 ID |
| supplierName | String | 厂家名称 |
| contactName | String | 联系人 |
| contactPhone | String | 手机号 |
| contactWechat | String? | 微信或邮箱 |
| totalRemark | String? | 总体备注 |
| expectedDelivery | DateTime? | 预计交期 |
| includeTax | Boolean | 是否含税 |
| includeShipping | Boolean | 是否含运费 |
| status | Enum (PENDING, PREFERRED, SELECTED) | 意向/中选状态 |
| submittedAt | DateTime | 提交时间 |
| createdAt | DateTime | 创建时间 |
| updatedAt | DateTime | 更新时间 |

### 2.7 QuoteItem（报价明细表）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | String (UUID) | 主键 |
| quoteId | String | 报价 ID |
| orderItemId | String | 订单明细 ID |
| price | Decimal | 报价金额 |
| remark | String? | 明细备注 |
| createdAt | DateTime | 创建时间 |
| updatedAt | DateTime | 更新时间 |

## 三、索引建议

- User: email (unique)
- Order: orderNo (unique), createdById, status
- OrderItem: orderId
- OrderAttachment: orderId, orderItemId
- QuoteLink: token (unique), orderId
- Quote: orderId, quoteLinkId, status
- QuoteItem: quoteId, orderItemId
