## 二、列表页布局（统一）

```
┌─────────────────────────────────────────────────────────┐
│ [主状态 Tab] 商机中 | 已成交 | 已取消                    │
├─────────────────────────────────────────────────────────┤
│ 搜索框  [筛选: 意向/已报价]  [+ 新建]                    │
├─────────────────────────────────────────────────────────┤
│ 编号/名称    客户    项目    主状态   [标签]  操作       │
│ XJ001        XX公司  项目A   商机中   已报价   [详情]    │
│ XJ002        YY公司  项目B   已成交   意向高   [详情]    │
└─────────────────────────────────────────────────────────┘
```

- 主状态：大 Tab 或醒目筛选
- 标签：小徽章，如 `已报价` `意向高` `外放` `已收`

## 三、订单详情页 Tab

```
┌─────────────────────────────────────────────────────────┐

```

## 四、操作精简

| 页面 | 主操作 | 次操作 |
|------|--------|--------|
| 商机列表 | 查看详情 | 新建 |
| 商机详情 | 转订单、更新状态 | 编辑 |
| 订单列表 | 查看详情 | 新建 |
| 订单详情 | 更新主状态 | 编辑、生成外协链接 |
| 报价回收 | 标记中标、更新状态 | - |

- 主状态更新：下拉选择 6 个状态之一，一键保存
- 避免多步骤、多弹窗
