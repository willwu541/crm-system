```
│   │   │   └── ...
│   │   ├── quote/

│   │   │       └── page.tsx   # 外协填写页（公开）

│   │       ├── auth/

│   │       ├── orders/

│   ├── components/
│   │   ├── ui/                # shadcn/ui 组件
│   │   ├── layout/
│   │   │   ├── Header.tsx
│   │   │   └── Sidebar.tsx
│   │   ├── orders/

├── package.json
└── tsconfig.json
```

## 二、关键目录说明

| 目录 | 说明 |
|------|------|
| `src/app` | Next.js App Router 页面与 API |
| `src/components` | 可复用组件 |
| `src/lib` | 工具、Prisma、认证等 |
| `src/hooks` | 自定义 Hooks |
| `prisma` | 数据库模型与迁移 |

## 三、扩展预留

- `src/lib/export/` - Excel/PDF 导出
- `src/lib/notification/` - 消息提醒
- `src/app/api/admin/` - 管理员 API
