# 外采加工询价管理系统 - 页面结构 (Sitemap)

## 一、整体结构

```
外采加工询价管理系统
├── 后台系统（需登录）
│   ├── /login                    登录页
│   ├── /dashboard                仪表盘（可选，V1 可简化）
│   ├── /orders                   订单列表
│   │   ├── /orders/new           新建订单
│   │   └── /orders/[id]          订单详情
│   │       ├── 编辑
│   │       ├── 生成外协链接
│   │       └── 查看报价
│   └── /admin                    管理员（V1 可选）
│       └── /admin/users          用户管理
│
└── 外协填写（无需登录）
    └── /quote/[token]            外协报价填写页（通过唯一 token 访问）
```

## 二、页面清单

| 路径 | 页面名称 | 说明 | V1 |
|------|----------|------|-----|
| `/login` | 登录页 | 内部用户登录 | ✅ |
| `/` 或 `/orders` | 订单列表 | 业务员/管理员查看订单 | ✅ |
| `/orders/new` | 新建订单 | 创建询价订单，支持多明细 | ✅ |
| `/orders/[id]` | 订单详情 | 查看/编辑订单、生成链接、查看报价 | ✅ |
| `/orders/[id]/links` | 外协链接管理 | 生成、复制、查看链接列表 | ✅ |
| `/orders/[id]/quotes` | 报价回收 | 比价、排序、标记中选 | ✅ |
| `/quote/[token]` | 外协填写页 | 匿名填写报价 | ✅ |
| `/admin/users` | 用户管理 | 管理员管理内部账号 | V2 |

## 三、导航结构

```
顶部导航栏
├── Logo / 系统名称
├── 订单管理 → 订单列表
├── 新建订单
└── 用户菜单（退出登录）
```

## 四、外协填写页流程

```
打开链接 → 展示订单信息与明细 → 展示图纸/附件 → 填写厂家信息与报价 → 提交
```
