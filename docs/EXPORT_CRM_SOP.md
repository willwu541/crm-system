# 外贸 CRM 使用 SOP

## 一、Leads 线索管理

### 1.1 如何录入
- **手动新建**：点击「新建线索」，填写公司名、国家、邮箱、电话等必填/选填信息
- **CSV 导入**：点击「导入 CSV」，上传符合模板的 CSV 文件，系统自动解析并创建线索
- **来源**：建议填写来源渠道（如 Alibaba、展会、Google）和来源关键词，便于后续分析

### 1.2 线索状态
- **新线索**：刚录入，待分配
- **待审核**：需主管审核
- **有效**：确认有价值，可跟进
- **无效**：放弃跟进
- **已转化**：已转为客户

### 1.3 何时转 Customer
- 当线索确认有采购意向、需要正式报价或进入商务谈判时，点击「转客户」
- 转化后系统自动创建客户档案，如有邮箱/电话会创建默认联系人
- 转化后线索状态变为「已转化」，可点击跳转至客户详情

## 二、Customer 客户管理

### 2.1 客户状态
- **待开发**：新客户，待首次联系
- **开发中**：已建立联系
- **已回复**：客户有回复
- **已报价**：已发送报价
- **谈判中**：价格/条款谈判
- **已成交**：订单成交
- **暂停**：暂时不跟进
- **已流失**：客户流失

### 2.2 客户工作台
- **基本信息**：公司、网站、国家、地址、负责人等
- **联系人**：可新增多个联系人，标记主联系人
- **跟进记录**：按时间线展示所有 Activity
- **报价 / 订单 / 任务**：关联的报价、订单、待办任务

### 2.3 快捷操作
- 新增联系人、新增跟进、新建报价、新建任务均可通过工作台顶部按钮在抽屉中完成，无需跳转

---

## 三、Activity 跟进记录

### 3.1 如何填写
- 点击「新增跟进」，选择类型（邮件/电话/WhatsApp/会议等）
- **主题**：简要描述本次跟进内容
- **内容**：详细记录沟通要点
- **客户反馈**：客户的主要回复或态度
- **下次跟进**：如有约定，填写下次跟进日期，系统会同步到客户卡片

### 3.2 填写建议
- 每次重要沟通后及时记录
- 记录客户对价格、交期、规格的具体反馈
- 设置下次跟进日期，便于 Dashboard 提醒

---

## 四、Quote 报价与跟进

### 4.1 创建报价
- 在客户工作台点击「新建报价」，或从 Quotes 列表新建并选择客户
- 填写报价日期、币种、Incoterm、有效期、产品摘要、总金额等
- 可添加明细行（产品类型、规格、数量、单价、金额）

### 4.2 报价后如何跟进
- 报价发出后，在 Activity 中记录「已发送报价」
- 若 3 天内无回复，Dashboard 会提醒「报价 3 天未跟进」
- 收到客户回复后，新建 Activity 记录反馈，并创建 Quote 跟进类型的活动
- 谈判中可多次更新报价状态（sent → replied → negotiating）

### 4.3 转订单
- 当客户确认订单时，在报价详情页点击「转订单」
- 系统自动创建订单并复制报价明细，报价状态变为「已成交」

---

## 五、Task 任务

### 5.1 如何使用
- 用于待办事项：如「下周一向客户发样品」「月底前确认付款方式」
- 可关联客户和联系人
- 设置截止日期和优先级

### 5.2 状态
- **待办**：未开始
- **进行中**：正在处理
- **完成**：已完成
- **超期**：截止日期已过未完成（自动显示）

### 5.3 建议
- 将重要跟进节点设为 Task，避免遗漏
- 每日查看 Dashboard「今日到期任务」和「超期任务」

---

## 六、Dashboard 如何看

### 6.1 待办提醒（优先处理）
- **今日待跟进客户**：nextFollowUpAt 为今天的客户
- **超 7 天未跟进**：超过 7 天无跟进记录的客户
- **今日到期任务**：截止日期为今天的任务
- **超期任务**：已过截止日期的未完成任务
- **报价 3 天未跟进**：报价发出超过 3 天无后续活动的列表

### 6.2 数据概览
- **本周新增 Leads**：最近 7 天录入的线索
- **本月 Quotes / Orders**：当月创建的报价和订单数量

### 6.3 统计
- **客户状态分布**：各状态客户数量，点击可筛选
- **国家分布**：客户按国家分布，点击可筛选

---

## 七、常用流程

1. **新线索** → 录入/导入 → 审核 → 有效则跟进
2. **有意向** → 转客户 → 补充联系人 → 新建报价
3. **报价发出** → 记录 Activity → 3 天内跟进
4. **客户确认** → 报价转订单 → 跟进生产/发货
5. **重要节点** → 创建 Task → 到期前完成并标记
