# 外采加工询价管理系统 - 产品需求文档 (PRD)

## 一、产品概述

### 1.1 产品定位
钢格板公司专用的「外采加工询价管理系统」，核心是：**内部建单 + 外协匿名报价回收**，而非传统 CRM。

### 1.2 目标用户
- **内部用户**：业务员、管理员
- **外部用户**：外协加工户（无需注册，仅通过链接填写报价）

---

## 二、业务流程

```
业务员登录 → 新建询价订单 → 添加多规格明细/图纸 → 生成外协链接 
    → 分发链接给加工户 → 加工户匿名填写报价 → 后台回收报价 
    → 比价/标记中选 → 完成询价
```

### 2.1 详细流程
1. 业务员登录后台
2. 新建询价订单，填写客户、项目、交货地区等主信息
3. 添加多个订单明细（规格、数量、要求、图纸）
4. 上传订单总图纸/附件
5. 系统为每个外协加工户生成唯一填写链接（带 token）
6. 外协加工户打开链接，查看订单信息与图纸，填写报价
7. 后台统一查看所有报价，进行比价
8. 标记意向/中选厂家

---

## 三、功能需求

### 3.1 订单管理
- 订单主信息：订单编号、客户名称、联系人、电话、业务员、项目名称、交货地区、报价截止时间、总体备注、状态
- 订单明细：支持多行，每行包含产品类型、规格型号、尺寸、数量、单位、表面处理、特殊要求、备注、明细图纸
- 订单级附件：总图纸、总附件

### 3.2 外协链接
- 每个链接唯一，带 token
- 支持设置过期时间
- 外协户无需登录，打开即填

### 3.3 报价回收
- 一个订单下可查看多家工厂报价
- 表格对比每家工厂每个明细项价格
- 支持按总价、交期、提交时间排序
- 支持标记意向/中选厂家

### 3.4 权限与角色
| 角色 | 权限 |
|------|------|
| 管理员 | 查看所有订单、管理账号、查看所有报价、标记中选 |
| 业务员 | 创建/编辑自己的订单、上传图纸、生成链接、查看自己订单的报价 |

---

## 四、非功能需求

- 后台界面简洁，适合业务员日常使用
- 表单支持动态增删订单明细
- 附件支持 pdf、jpg、png、zip 等
- 外协链接支持过期
- 预留 Excel 导出、PDF 导出、消息提醒扩展点

---

## 五、V1 最小可用版本范围

1. 内部登录（管理员/业务员）
2. 订单建单（主信息 + 多明细 + 附件）
3. 外协匿名链接生成与填写
4. 报价回收与后台比价
5. 标记意向/中选厂家

**V1 不包含**：Excel 导出、PDF 导出、消息提醒、复杂权限配置
