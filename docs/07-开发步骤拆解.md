# 外采加工询价管理系统 - 开发步骤拆解

## 阶段一：项目基础（当前阶段）

1. **初始化 Next.js 项目**
   - 创建 Next.js + TypeScript + Tailwind 项目
   - 安装 Prisma、shadcn/ui
   - 配置环境变量

2. **数据库设计**
   - 编写 Prisma schema
   - 执行迁移
   - 编写 seed 脚本（初始管理员账号）

3. **登录模块**
   - 登录页 UI
   - 认证 API（Session 或 JWT）
   - 路由保护中间件

4. **订单列表页**
   - 订单列表 API
   - 列表页 UI（表格、分页、筛选）
   - 后台布局（导航栏）

5. **新建订单页**
   - 订单表单（主信息）
   - 动态订单明细表单（增删行）
   - 附件上传（订单级 + 明细级）
   - 新建订单 API

## 阶段二：外协与报价

6. **外协链接**
   - 生成链接 API
   - 链接管理 UI（复制、过期时间）
   - 外协填写页（公开，无需登录）
   - 外协提交报价 API

7. **报价回收**
   - 报价列表 API
   - 报价对比表格 UI
   - 排序（总价、交期、提交时间）
   - 标记意向/中选 API 与 UI

## 阶段三：完善与优化

8. **订单详情与编辑**
   - 订单详情页
   - 编辑订单
   - 订单状态流转

9. **测试与修复**
   - 端到端流程测试
   - Bug 修复
   - 样式与交互优化

## 阶段四：V2 扩展（后续）

10. Excel 导出
11. PDF 导出
12. 消息提醒
13. 管理员用户管理
14. 更多权限与审计
